## Objectives

1. Implement standard HTML layout tags (`<header>`, `<nav>`, `<main>`, `<aside>`, `<section>`, `<footer>`) based on W3Schools guidelines.
2. Build site navigation and sidebar menus using unordered lists (`<ul>`, `<li>`, `<a>`).

---

## HTML Structure Breakdown

- **`<header>`**: Displays site title and tagline.
- **`<nav>`**: Top navigation menu for core links (Home, Library, Import, Settings).
- **`<aside>`**: Sidebar menu for filtering book categories (All Books, Reading, Completed).
- **`<section>` & `<article>`**: Main content area holding ePub book cards.
- **`<footer>`**: Bottom section containing copyright text.
