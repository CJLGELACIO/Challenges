## Objectives

1. Implement essential HTML `<head>` tags in the ShelfSpace project based on W3Schools standards (`https://www.w3schools.com/html/html_head.asp`).
2. Include metadata (`<meta>`), document title (`<title>`), character encoding, viewport configuration, author details, and favicon link (`<link>`).

---

## HTML Implementation Code

```html
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>ShelfSpace - Digital ePub Reader &amp; Library</title>
  <meta
    name="description"
    content="ShelfSpace is a simple, distraction-free web-based ePub reader and personal digital library."
  />
  <meta
    name="keywords"
    content="ShelfSpace, ePub, eBook Reader, Digital Library, Web Reader"
  />
  <meta name="author" content="CJ Gelacio" />
  <link rel="icon" type="image/x-icon" href="favicon.ico" />
</head>
```
