# Documentation: Challenge #4 — Implementation of Favicon

- **Project:** ShelfSpace

---

## Objectives

1. Implement a browser favicon in the HTML document using standard `<link>` tags per W3Schools specifications.
2. Link a custom favicon image file (`favicon.ico`) to display on the browser tab next to the page title.

---

## HTML Implementation Code

```html
<head>
  <meta charset="UTF-8" />
  <title>ShelfSpace - Digital Library</title>
  <!-- Favicon Implementation -->
  <link rel="icon" type="image/x-icon" href="favicon.ico" />
</head>
```
