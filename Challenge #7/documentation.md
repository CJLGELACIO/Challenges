## Implementation Details

### 1. Block Elements

Block elements start on a new line and take up the full available width. In this project, elements such as `<header>`, `<nav>`, `<main>`, `<aside>`, `<section>`, `<article>`, `<div>`, and `<p>` act as block-level containers structuring the page layout.

### 2. Inline Elements

Inline elements do not start on a new line and only take up as much width as necessary. Examples used include `<a>` (anchor links), `<strong>`, and `<span>` tags (such as `<span class="book-author">` and `<span class="highlight-status">`).

### 3. HTML Class Attribute

Classes are used to apply styles to multiple elements sharing common characteristics.

- Example class `.book-author` styles author text across book cards.
- Example class `.highlight-status` highlights reading badges inline.

### 4. HTML Id Attribute

IDs provide a unique identifier for a single specific element on the page.

- Example ID `#featured-article` and `#featured-book-title` target unique headings and sections.
