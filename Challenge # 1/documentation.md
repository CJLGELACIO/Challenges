## 1. Website Goal

**Concept**: ePub Reader & Library
_ShelfSpace_ is a modern, distraction-free web application designed for reading and managing ePub electronic books directly in the browser. Traditional eReader software often requires bulky desktop installations or proprietary apps. ShelfSpace provides a lightweight, self-contained, offline-capable digital bookshelf where users can effortlessly upload .epub files, organize their personal library, and customize their reading experience with responsive typography, custom font families, and multiple ambient reading themes (Light, Sepia, Dark).

## 2. Technical Stack

- HTML 
- CSS
- JS

* _HTML5 & CSS3:_ For the core page structure and styling.
* _Tailwind CSS:_ For clean, modern UI design and layout.
* _JavaScript:_ For handling file uploads and reading logic.
* _ePub.js:_ A JavaScript library used to parse and display ePub books chapter by chapter.
* _Browser Local Storage / IndexedDB:_ To save uploaded books locally on the computer so they don't disappear when the browser is closed.

## 3. Key Features

- _Book Upload:_ Easily select and import .epub files from your computer.
- _Library View:_ A visual dashboard showing your uploaded books.
- _Reader View:_ A clean reading screen with next/previous page buttons.
- _Dark & Light Mode:_ Toggle between light and dark themes for comfortable reading.
- _Local Storage:_ Books are saved locally in the browser so no internet connection or server is needed.

## 4. Implementation Timeline

- _Week 1:_ Design the basic layout (library grid and reader screen) using HTML and CSS.
- _Week 2:_ Integrate JavaScript and ePub.js to handle file uploading, parsing, and page navigation.
- _Week 3:_ Add local storage so books stay saved, polish the user interface, and prepare for presentation.

## 5. Inspiration

The goal was to create a lightweight, offline tool to read ePub books without needing to install heavy software or create online accounts.
